# 伤势：部位受伤挂状态效果

身体绑着的实体（玩家和带人体的生物），某个部位伤到一定程度就挂上对应的状态效果，带数值后果；HP 回到门槛以上就撤。
效果跟着身体走，不存倒计时。配置在 `meridian-vanilla-healing.toml` 的 `[injury]` 一节。

## 两档

- **受伤**：部位 HP 不高于上限的一半（`injured_ratio = 0.5`）。
- **归零**：部位 HP 为零。
- 一组里有几个部位（两条腿各三段），取伤得最重的那个。人死了不挂。

## 效果表

强度都是乘在原值上的倍数，下面是随包初值。

| 部位 | 受伤 | 归零 | 效果 |
|---|---|---|---|
| 腿：大腿、小腿、足 | 移速 ×0.85 | 移速 ×0.60，跳跃 ×0.50，不能疾跑 | 腿伤 Ⅰ / Ⅱ |
| 骨盆 | 移速 ×0.90 | 移速 ×0.70，不能疾跑 | 胯伤 Ⅰ / Ⅱ |
| 手臂：上臂、前臂 | 攻击 ×0.80，挖掘 ×0.70 | 攻击 ×0.50，挖掘 ×0.30 | 臂伤 Ⅰ / Ⅱ |
| 手 | 算手臂受伤一档 | 算手臂受伤一档，而且这只手拿不住东西 | 手废（外加臂伤 Ⅰ） |
| 腹 | 饥饿消耗 ×1.5 | 饥饿消耗 ×3 | 腹伤 Ⅰ / Ⅱ |
| 胸 | 疾跑时饥饿消耗再 ×2，水下氧气消耗 ×2 | （归零即死） | 气短 |
| 颈 | 攻击 ×0.80，挖掘 ×0.70 | （归零即死） | 颈伤 |
| 头 | 每挨一下 5 秒原版反胃；常驻头晕：真元摄入 ×0.70 | （归零即死） | 头晕 |
| 两眼（器官） | — | 两只都归零：原版失明 | 失明 |
| 肺（器官） | — | 坏一边：气短；两边都坏：再加移速 ×0.80 | 气短 |

几条要知道的：

- **手臂只算惯用手那条**：原版只有主手能攻击、能挖，副手那条手臂伤了照样挂「臂伤」，但没有数值可减。颈伤两只手都算，和手臂的倍数连乘。
- **手归零**：那只手里的东西掉在脚下，2 秒内捡不起来；之后再放进那只手的也掉。左右手各管各的，生物掉的是手里的兵器。
  会捡东西的生物也不往归零的手里捡（护甲照常能捡），掉在地上的兵器就留在地上，直到手治好。
- **不能疾跑**：按身上有没有腿伤 Ⅱ、胯伤 Ⅱ 来拦，客户端和服务端都拦（疾跑是客户端自己决定的）。
- **移速倍数说的是实际走得多快**，玩家和生物一样。原版生物走路的实际速度跟移速属性的平方走（缓慢药水也是这样），
  所以给生物的移速属性乘的是倍数的平方根（×0.85 的伤，属性乘 0.922），走出来就是 ×0.85；玩家的实际速度跟属性成正比，照倍数改。
  真客户端连拍 `leg` 里量了三个卫道士同样时间各走多远，和配置的 0.85、0.60 各差不超过 0.03。
- **头晕**：这套系统里真元是肺从环境摄入的，所以做成给每边肺挂一条「摄入 ×0.70」的能力修正（来源 `meridian_vanilla_healing:injury`，ID `meridian_vanilla_healing:dizzy/<肺的 ID>`）。
  框架规定一条能力修正最长 5 分钟，所以 4 分钟一条、剩一半时换新的；头回到一半以上就撤，人死了由核心清掉。经活动宿主提交。
- **失明**用的是原版失明：只认本附属挂的那种（无限时长、环境效果、不出粒子），别处来的失明不动。

## 什么时候算、什么时候挂

- 每次身体同步时重新算一遍：受伤、治疗、黄心变化之后立刻算，另外每秒兜底一次。只读同步时手上的那份身体，不另外查询宿主。
- 算出来的结果在下一个实体 tick 落到实体上。这样挂效果、掉东西不会发生在一次伤害的结算中途。
- 属性倍数是不进存档的临时修正；进世界后第一次同步就重新挂上。

## 牛奶解不了

- 八个伤势效果在状态效果标签 `#meridian_vanilla:incurable` 里。喝牛奶、`/effect clear` 清「全部」时跳过标签里的效果，其余照常清。
- 别的附属有「解不了」的效果，往这个标签里加就行。
- 点名清除（`/effect clear <人> <效果>`）照样能清，但一秒左右又会挂回来。

## 配置

```toml
[injury]
enabled = true              # false 整套关掉
injured_ratio = 0.5         # (0, 1)
head_hit_nausea_ticks = 100 # 0 表示头挨打不给反胃

[injury.parts]              # 每组看哪些部位（身体模板里的部位 ID）；写成空表就是不看这一组
[injury.organs]             # eyes、lungs 各是哪些器官
[injury.strength]           # 每条效果的倍数，见随包文件里的注释
```

- 这一节是后加的：老配置文件里整节没有、或者缺后来加的键，都按随包初值算。
- 拼错的键、类型不对、越界的值会拒绝启动。移速、跳跃、攻击、挖掘、真元摄入只能写 (0, 1]；饥饿、氧气消耗只能写 [1, 10]。
- 部位和器官的 ID 只出现在配置里，代码不认识人体；身体上没有配置里写的部位就不看它。

## 没做的

- 胃、肠、肝等器官归零没有效果。
- 心归零即死在 Human 的判死规则里，不在这里。
